# Lull Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Lull, a native macOS menu bar app that plays GIFs and looping videos as a very light desktop wallpaper.

**Architecture:** A SwiftPM package with `LullCore`, a library of testable logic with no UI, and `Lull`, the AppKit and SwiftUI executable. Files are prepared once into HEVC by the importer, then played by one shared `AVQueuePlayer` feeding a desktop-level window per display. A pure `PauseRule` decides when to play, and the player is fully unloaded when paused.

**Tech Stack:** Swift 6, AppKit, SwiftUI, AVFoundation, VideoToolbox, ImageIO, ServiceManagement, Swift Testing. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-11-06-lull-design.md`

## Global Constraints

- Deployment target macOS 15.4, Apple Silicon only, no third-party dependencies.
- Bundle ID `com.markoderic.lull`. `LSUIElement` true.
- Never call `NSWorkspace.setDesktopImageURL`.
- User-facing copy is sentence case, with no "please", no "successfully" and no raw error strings.
- Debug automation is compiled only under `#if DEBUG`.

## Review Focus

- A GIF with odd pixel dimensions must import. HEVC rejects odd sizes, so the output is rounded up to even.
- A wallpaper with one frame must import as Still and must not offer Animated.
- A corrupt `info.json` must hide only that wallpaper and must not break the others.
- Deleting the active wallpaper must remove the window so the normal wallpaper shows, with nothing left playing.
- Pausing and resuming quickly must not leave a player running while the app believes it's paused.
